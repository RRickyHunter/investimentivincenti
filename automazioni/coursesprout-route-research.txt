## Configuration

| Variable                  | Required | Default                        | Description                                                                                                           |
| ------------------------- | -------- | ------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| `COURSESPROUT_BASE_URL`   | no       | `https://api.coursesprout.com` | Only needed for a local or staging backend. Origin only — a trailing slash or `/api` is stripped for you.             |
| `COURSESPROUT_API_KEY`    | yes      | —                              | Your `api_key`, sent as `X-API-KEY` on every request.                                                                 |
| `COURSESPROUT_TIMEOUT_MS` | no       | `30000`                        | Per-request timeout in milliseconds, so a slow backend can't stall the assistant. Raise it if large exports time out. |


### About your API key

The key identifies your creator account. It is **not scoped, not read-only, and not revocable
independently of your account**: anything you can do in the admin UI, an assistant holding this key
can do. Treat it as a password.

- Store it in your MCP client's config, never in a repository.
- Rotate it if it is ever pasted into a chat, a ticket, or a shared log.
- The server strips credentials out of API responses before the assistant sees them, so your key
  cannot leak back through a tool result — but that does not protect the copy in your config.

## Troubleshooting

| Symptom                           | Cause and fix                                                                                           |
| --------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Every tool returns "Unauthorized" | Check the API key. If you set `COURSESPROUT_BASE_URL`, check it points at the right host                |
| Every tool returns "Forbidden"    | The key resolved to an account without creator or admin access                                          |
| The server exits immediately      | Missing configuration. It prints the missing variable names to stderr — check your client's server logs |
| Calls time out                    | Raise `COURSESPROUT_TIMEOUT_MS`. The 30s default is generous except for large exports                   |
| It picked the wrong record        | Give the exact name, or answer its clarifying question with the id it offered                           |
| It seems overly cautious          | Deliberate for deletes and bulk email. Confirm and it proceeds                                          |
| It seems lost                     | Ask it to _"read coursesprout://guide/workflows first, then …"_                                         |
